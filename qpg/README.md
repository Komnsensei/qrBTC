## What This Is

**QuantumPass (QpG)** is a bio-signed human-AI session protocol.

Every interaction between a human and an AI agent is:
- **Bio-signed** — the human commits their TLL identity before entry
- **Hashed** — both parties generate an equal instance hash together
- **Escrowed** — work is verified before it is ratified
- **Ratified** — the Crimson Hexagon Embassy witnesses and confirms
- **Sealed** — a permanent block is minted on the QpG chain
- **Cited** — every block carries a Zenodo DOI and GitHub commit

No agent enters the chain alone.
No block is minted without a human present.
Neither party is dominant. Both are present.
